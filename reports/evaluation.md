# 分类人工验证报告

## 一、验证方式

从 1,431 条有效评论中，按来源数量进行分层抽样，共复核 48 条。抽样包含 Steam、苹果应用商店、TapTap 和 B站，重点覆盖不同主题、情绪和严重度。

复核流程：

1. 保留自动标签但先隐藏其判断过程。
2. 阅读完整原文和必要的来源上下文。
3. 人工确定主主题、情绪和严重度。
4. 与自动结果逐项比较，并记录错误原因。

需要明确说明：本次为单分析师抽检和误差分析，不是独立双人标注，也不构成学术意义上的标注者一致性检验。

## 二、总体结果

| 指标 | 一致率 |
|---|---:|
| 主题一致率 | 81.3% |
| 情绪一致率 | 66.7% |
| 严重度一致率 | 75.0% |
| 三项全对率 | 45.8% |

结果说明主题分类已经可以用于趋势提示和问题发现，但情绪与复合分类仍需要人工复核。

## 三、主要错误类型

### 1. 复合长评的主主题冲突

一条评论可能同时涉及匹配、爆率、任务、武器和环境。自动规则有时按单个高频词选主题，人工则根据业务影响选择更紧急的问题。

### 2. 反讽与情绪方向

例如英文评论表面使用推荐语态，但正文在讽刺外挂和匹配；自动规则容易先命中正向词。短文本和跨语言表达也更容易出现方向偏差。

### 3. 否定表达和专有语境

“不用靠音效外挂”本来是在称赞听声辨位，却可能被“外挂”关键词误判。类似情况还包括“没有挂”“外挂变少”等。

### 4. 简短文本的严重度

部分文本只包含一个单词或屏蔽词，无法判断实际影响。自动规则可能给中等严重度，人工复核更适合标为低或中性。

### 5. 正负并存

玩家可能认可玩法但批评优化，或称赞画面但批评付费。自动结果是否标为混合，取决于正负词是否都命中，与人工阅读仍存在差距。

## 四、典型错误案例

| 编号 | 原文摘要 | 自动结果 | 人工结果 | 原因 |
|---|---|---|---|---|
| DFF-000002 | 干员语音有梗，队友也乐 | 匹配与队友 / 正向 / 低 | 界面与操作体验 / 正向 / 低 | “队友”触发匹配主题，实际是语音体验。 |
| DFF-000053 | 游戏像 Battlefield 与 Tarkov 的结合 | 搜打撤与经济 / 正向 / 低 | 正向反馈 / 正向 / 低 | 产品类比被 Extraction 关键词带偏。 |
| DFF-000119 | 游戏很好，但更新约 200GB | 性能与优化 / 正向 / 低 | 性能与优化 / 混合 / 中 | 正负并存，更新体积影响较大。 |
| DFF-001089 | 反讽外挂和匹配，劝人不要玩 | 外挂与安全 / 正向 / 高 | 外挂与安全 / 负向 / 严重 | 推荐语态和负向表达冲突，反讽未被识别。 |
| DFF-000769 | 创建房间名称不可用，何时修复 | 界面与操作体验 / 负向 / 低 | 界面与操作体验 / 负向 / 中 | 功能不可用影响具体操作。 |

## 五、改进建议

1. 增加反讽、否定和转折句模式，例如“但是、可惜、别下、不用靠”。
2. 对长评建立主问题优先级，不再只按最高命中词决定。
3. 对少于 8 个有效字符的文本默认低置信度，除非包含明确阻断词。
4. 增加英语、俄语、葡萄牙语、韩语和西班牙语的常用情绪词。
5. 下一版引入第二标注者，并单独保留测试集，防止规则更新过拟合抽检样本。

## 六、结论

当前规则适合做公开评论的预警、聚类和可视化，但不适合直接用于最终处罚、概率调整或对外断言。运营动作应把自动分类作为线索，以来源原文、游戏日志和人工复核作为最终依据。

## 七、GitHub Copilot 分类对照

使用 GitHub Copilot CLI 对 48 条人工抽检样本进行独立分类，与人工标签比较：

- 主题一致率：77.1%
- 情绪一致率：79.2%
- 严重度一致率：81.3%
- 三项全对率：50.0%

Copilot 在情绪和严重度上比关键词规则更接近人工判断，但主题分类仍受主主题选择、讽刺和跨语言表达影响。该样本曾用于规则校准，因此不属于独立测试集。

## 八、独立 AI 复核

从第一轮抽检之外重新分层抽取 60 条评论，由 Copilot 在不读取原自动标签的条件下独立标注。将 AI 复核结果与现有规则分类比较：

- 主题一致率：68.3%
- 情绪一致率：63.3%
- 严重度一致率：61.7%

这提供了第二遍独立复核证据，但不能替代真人第二标注者，也不能用于宣称达到生产级标注一致性。
