# 面试官导览

1. 先看根目录 `index.html`，用 1 分钟了解项目定位和关键指标。
2. 再打开 `dashboard/index.html`，筛选“外挂与安全”和“搜打撤与经济”。
3. 查看 `portfolio/case-study.pdf`，快速理解问题、洞察、动作和局限。
4. 需要技术细节时查看 `src/`、`data/processed/` 与 `reports/classification-standard.md`。
5. 作品集不宣称模型训练、业务上线效果或全量玩家代表性。
